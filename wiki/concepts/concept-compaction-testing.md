# Concept: Compaction Testing

**Type:** Concept
**Division:** Division 200 — Earthwork / Division 300 — Base Courses
**Section:** 203, 206, 304, 305

---

## Summary

Field compaction is the one area of the Sampling and Testing Guide where the stated frequency is explicitly **not** a requirement. Note 6G says the field compaction testing frequency for soils and aggregate materials is provided as a preliminary guide and should be project specific, finalized and documented by the Project Engineer. Every compaction frequency in the geotechnical tables inherits that qualifier. Quoting one as a fixed requirement misrepresents the source, and it is the most commonly misquoted item in the Guide. The correct answer to "how often do I run compaction tests" is the guide value, plus the fact that the PE sets and documents the real number for the project.

---

## What Note 6G Establishes

- **The PE owns the frequency.** It must be project specific, finalized, and documented. Where necessary, consult the HDOT project Geotechnical Engineer or LABS for a recommended frequency.
- **Lift thickness and test interval.** Compact each lift to approximately 6 inches. Perform a density test every other lift.
- **Gauge correlation.** For every 50 field compaction tests by nuclear or e-gauge method, or every 6 months, whichever comes first, perform one sand cone test side by side with the gauge, per HDOT TM 1-00 and TM 3-00. Results should agree within 3 percent compaction.
- **Fallback where frequency is uncertain.** Test every other lift per 300 lineal feet or 1,000 square feet.
- **Monthly reporting.** Submit a compaction sample card monthly and at project end.

---

## Required Contents of the Compaction Sample Card

1. PDF of the month's compaction summary, for the record
2. Excel file of the month's compaction summary, for data consolidation, numbered sequentially and cumulatively throughout the project
3. Sand cone test results
4. For nuclear or e-gauge, the additional information indicated on the LABS website or in the applicable gauge guide
5. All maximum density results used in the card, from laboratory Proctor tests

Numbering that restarts each month is a common finding. The Guide requires it to be cumulative across the whole project.

## Guide Values by Material

These are the preliminary values that Note 6G qualifies. Cited by item in the geotechnical tables.

| Material | Guide compaction frequency | Item |
|---|---|---|
| Cut subgrade | Visual inspection and probe rod for stiffness; minimum one field density test per soil type if the Engineer determines it necessary | 13.B |
| Embankment fills and import borrow | Every other lift per 10,000 cubic yards | 14.B |
| Structural backfill | Every other lift per 1,000 square feet | 15.C |
| Trench backfill | Every other lift per 300 lineal feet | 16.C |
| Aggregate base course | Every other lift per 1,000 square feet | 17.C |
| Aggregate subbase | Every other lift per 1,000 square feet | 18.C |

Note the unit differences: cubic yards for embankment, square feet for base and backfill, lineal feet for trench. The source PDF prints these as superscript exponents that text extraction can displace, so confirm the unit rather than reading a bare digit. See the extraction note in `00-general-notes.md`.

---

## QRSE Notes

- Ask for the PE's documented compaction frequency at project start. If it does not exist, that is the gap to close, and the guide fallback applies in the meantime.
- The 50-test or 6-month sand cone correlation is easy to miss on a long project. Track the count from the first gauge test, not from the current month.
- A gauge that drifts outside 3 percent against the sand cone undermines every density result taken with it. Treat a failed correlation as retroactive, not just forward looking.
- Subgrade is the exception to the pattern: the baseline is visual inspection and probe rod, with a density test only where the Engineer determines it is necessary.

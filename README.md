# HDOT Knowledge Base

A structured, searchable Markdown knowledge base built from official Hawai'i Department of Transportation (HDOT) Highways Division reference documents — the 2005 Standard Specifications for Road and Bridge Construction, Special Provisions, and related official manuals.

Maintained by QRSE LLC for internal contract-administration reference. Content is authored and kept current with Claude.

## What's here

- `raw/` — official source documents converted to Markdown, organized by division/section
- `wiki/` — compiled reference pages: one per division/section (`wiki/divisions/`) and one per cross-cutting concept (`wiki/concepts/`), each summarizing the applicable spec language plus practice notes
- `indexes/` — a source index, concept index, glossary, and an open-questions log tracking ambiguities and gaps identified during the build

## Status

Actively being built out. Currently covers the 2005 Standard Specifications (partial) plus a small set of concept pages. Special Provisions and additional official HDOT reference manuals (Standard Plans, materials/testing guides, stormwater/BMP manuals, and others) are being added incrementally.

## Scope and limits

This is a reference aid, not a legal document. Wiki pages summarize and interpret official HDOT publications; they are not a substitute for the source specifications, special provisions, or current HDOT guidance, which remain authoritative. Always verify against the official source before relying on anything here for a live contract decision.
